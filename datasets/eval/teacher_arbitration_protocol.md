# 二语教师仲裁协议（P2-1，待执行）

> 版本：草案 0.1；建立日期：2026-09-29。本文件是后续邀请真实教师工作的操作协议，不代表当前语料已由教师标注或仲裁。当前 `golden_v1_4.json` 的 `arbitrator=self-review` 是作者自审；`calibration_report.json` 中的 judge-human κ 是模型评分校准，不是识别金标的教师间一致性。

## 1. 冻结与样本范围

首批待审队列见 [`teacher_arbitration_queue.md`](teacher_arbitration_queue.md)。保留源文件原样，先记录源文件 SHA-256 和仓库提交，再复制去标签的标注包。不得把现有 `truth`、`corrected`、`golden_status` 或模型输出作为第一轮提示；语境字段和学习者等级可显示。若样本无必要语境，允许标“信息不足”，不得强行判错。

可运行 `python -m datasets.eval.prepare_teacher_pack --teacher-pack <新文件> --coordinator-map <另一个新文件>` 生成首批盲标包。两个输出都应放在仓库和同步盘之外、权限受限的目录。源 ID（例如 `:partial` 后缀）只保存在协调者映射；教师只收到 `--teacher-pack`，不得把整个输出目录或映射文件一起转交。两位教师各自填写同一盲标包的独立副本。

## 2. 独立标注

至少两位有对外汉语/中文二语教学经验的教师独立标注；记录匿名标注者 ID、资格、日期、标注包版本与样本 ID。第一轮互不看对方答案及原金标。每条记录：`label`（偏误 / 可接受 / 语境依赖 / 信息不足）、偏误跨度、类型（语法 / 词汇 / 语用 / 汉字 / 其他）、严重度、可接受的多个改写、理由及证据、置信度。复述样本另判 `pass / partial / hollow / fail / 信息不足`，列出实际覆盖的教学要点与等价表达。空白字段必须显式标为“不适用”或“待确认”。

## 3. 分歧与终裁

先保留两份原始独立标注，再汇总分歧；不能覆盖原始记录。遇到标签、跨度、类型或可接受改写分歧，由第三位具有相同领域经验的教师盲审并主持讨论；记录最终标签、采纳理由、反对意见、规则版本、日期和终裁人 ID。仍无共识则保持 `disputed`，退出主指标分母，单列敏感性分析。作者或 AI 可以整理材料，但不能替代教师终裁。

## 4. 统计与入库

在终裁前报告原始一致率与适合标签类型的机会校正一致性（例如二分类 Cohen's κ；多标注者或缺失标注可评估 Krippendorff's α），同时给样本数、类别分布、置信区间与分歧矩阵。跨度一致性单独计算，不能只报标签 κ。只有完成独立标注与终裁后，才复制形成新版本金标；保留旧版、变更日志及复算脚本。无论结果如何，不能把现有 36 句自建集直接称为行业基准或学习增益证据。

## 5. 隐私与使用边界

仅使用可授权的匿名化样本；真实学习者语料须先确认来源许可、去标识化、保留期限和删除流程。教师和学习者的招募、付费、同意书及伦理要求由项目负责人另行确定，本草案不代替该审批。
