# M10 · 前端壳实施方案

> **任务**：M10 前端壳（认知地图 + 费曼对话的交互界面）——把 CLI 形态升级为可演示、可交互的产品。
> **状态**：方案已确认；技术选型用户拍板。
> **配套**：数据契约见 `datasets/docs/JSON-接缝契约-v1.md`；方向草案见 `datasets/docs/M10-前端壳草案.md`。

---

## 0. 一句话

**借鉴 Explore 的交互范式（项目树 / 对话+文档双通道 / 卡片网状 / 知识宇宙），装我们确定性偏误图谱的内核——界面自由，数据规则。**

前端壳只渲染**确定性图谱** + 调契约化引擎，不让 LLM 的自由联想进入用户"宇宙"的边。

## 1. 技术选型（用户已拍板）

| 维度 | 选择 | 理由 |
|------|------|------|
| 前后端桥接 | **标准库 HTTP 服务 + 纯 JS** | 兼顾"能本地跑通"与"不破坏零依赖" |
| 画布 | **原生 JS + SVG** | 零框架/CDN、可离线、单文件；契合零依赖哲学 |
| 数据交互 | 前端 fetch 契约 JSON，后端 `Router.process` POST | 与 4.4 契约 v1 无缝衔接 |

**零依赖铁律**：前端不引任何 npm/CDN 库；后端只用 Python 标准库 `http.server`（不新增第三方依赖）。

## 2. 架构

```
index.html (原生JS+SVG, 单页)
   │  fetch  (契约 JSON, JSON-接缝契约-v1.md)
   ▼
serve.py  (Python 标准库 http.server)
   │  提供两条 API + 静态托管
   ├── POST /api/process   → Router.process(text) → 契约 v1 result
   ├── GET  /api/graph     → ErrorGraph.to_dict()（nodes/edges/queue）
   └── GET  /              → 托管 index.html
```

- **服务层** `serve.py`：零第三方依赖，`python -m engine.serve` 启动；设置 `DEEPSEEK_API_KEY` 走真实识别，否则走 4.2 规则回退降级（契约 degraded 记录）。
- **前端** index.html：输入中文 → POST `/api/process` → 渲染偏误卡（四段式讲解）+ 更新认知地图 + 复习队列；3.1 契约测试确保往返稳定。

## 3. 页面布局（借鉴 Explore，剥离自由发散）

1. **顶栏**：项目/学习者切换（learner_id → 对应 `data/graph_<id>.json`）。
2. **左/主对话区**：输入框 + 偏误卡（error→讲解→复述验证的入口）。
3. **认知地图区**：SVG 散点图——X=level（HSK1-6 由左到右）、Y=mastery（0-1，下大上小）；节点大小∝error_count、颜色∝优先级；边=混淆边（confusion edge，只画已确认）。**沿权威边生长，无自由发散**。
4. **复习队列区**：`/api/graph` 的 queue 按 priority 降序，呈"下一张复习卡"。

## 4. 认知地图·确定性约束（对照草案 §核心差异）

- 只渲染 `Graph` 已确认的 `nodes/edges`（Edge relation 限定 confusion/is_confusion）。
- 用户"建议新边"→ 走待确认队列，**确认后才入图谱**——不在画布自由画线。
- 画布视觉"像自由白板"，但每条边背后是确定性图谱路由（2.4）。

## 5. MVP 范围

- **做**：单学习者 + 纠错对话 + 认知地图渲染（nodes/edges/priority）+ 复习队列。
- **不做**（MVP 后）：多学习者云同步、语音、跨端、文档讲解分支的 UI（保留 file_mode 接口，前端后续对齐）。

## 6. 验收

1. `python -m engine.serve` 启动后，浏览器打开 `http://localhost:8xxx` 能输入中文、得到偏误卡 + 讲解 + 地图 + 队列。
2. 免 Key 启动：不崩、走规则回退降级、地图仍能渲染已有图谱。
3. 契约对齐测试覆盖服务层路由/JSON 往返，全量绿。
4. 认知地图**只有已确认的权威边**，无自由发散路径（用手动核验）。
