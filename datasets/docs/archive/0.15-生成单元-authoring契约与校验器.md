## 3. 对齐 schema v1 的关键口径（写死进 prompt）

- **keyPoints 只装正向目标知识**，不装纠错指令/错误特征（呼应已签核教训"宁漏勿错"）。
- **forbidden_errors 允许空数组但不可缺省/置 null**（缺省=护栏失效）。
- **previousSpeech 只注入最近一口**，不得承载纠错结论（防发散）。
- **curriculumAt 只读**，绝不参与写回（图谱唯一权威）。
- **difficulty 由服务层注入，不信任生成侧自报**（0.7 §7.4，防难度虚标）。
- 三个后置字段（dialogueSpec/interactiveSpec/pblSpec）一律 `null`，仅类型位。
- type 必须是枚举，禁止自由造词；title ≤20 字不与 allTitles 重复。

## 4. 校验器诊断码（P2 稳定 code 全集）

| code | order | 触发 |
|---|---|---|
| `code_invalid_json` | 0 | 非合法 JSON |
| `code_unknown_type` | 0 | type 非 explain/practice |
| `code_missing_required` | 1 | 缺必选字段 |
| `code_field_wrong_type` | 1 | 字段类型错 |
| `code_task_kind_invalid` | 1 | practice.task_kind 非枚举 |
| `code_forbidden_missing` | 2 | forbidden_errors 置 null |
| `code_keypoints_empty` | 2 | keyPoints 为空 |
| `code_postponed_not_null` | 3 | 后置字段非 null |
| `code_context_mismatch` | 3 | context 缺 curriculumAt |
| `code_title_dup` | 4 | title 与 allTitles 重复 |
| `code_title_too_long` / `code_question_count_high` | 5 | 结构/题量越限 |

- 每个诊断含 `evidence`（实测值）与 `supported_fixes`，**可被机器消费**（对齐 0.8 P2"不是人读的一行字"）。
- 返回按 repair_order 升序，**先修正确性再说美观**（0.8 P3，绝不为了过校验删语义）。

## 6. 边界声明（诚实标注）

- 本 M **只落 authoring prompt + 校验器样板**，不含完整生成引擎（LLM 调用、JSON 自愈重试、写回图谱）——那些属生成引擎实现期，本 M 范围明确收在"作者侧契约 + 机器侧校验"。
- 校验器是"可移植样板"，不一定在 M10 全量接入前端壳；接入与否由 M10 方案定。
- 零依赖：仅标准库（re/json/os），无 LLM 运行时依赖（validator 纯确定性）。
