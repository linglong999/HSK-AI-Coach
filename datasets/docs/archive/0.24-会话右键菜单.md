# 0.24 · 会话右键菜单（置顶 / 分享 / 重命名 / 删除）（2026-09-05）

## 一、背景与目标

用户要求：右键会话栏里的会话项，弹出「置顶、分享、重命名、删除此对话」四项操作，
交互范式对标个人工作台任务列表栏的右键上下文菜单（图标 + 文字紧凑列表、危险操作红色警示、删除二段确认）。

## 二、核心决策

| 决策点               | 结论                                                                                               |
| ------------------- | ------------------------------------------------------------------------------------------------ |
| 置顶                | 置顶项跳动会话列表首位（profile 排序 `(not pinned, -updated_at)`）；再次右键变「取消置顶」；列表图标 📌       |
| 置顶/重命名语义       | **管理操作不改变 `updated_at`**（`touched(pinned, bump=False)`），排序只反映真实对话活跃度                 |
| 分享                | 拉取会话历史 → Markdown 转写（`# 标题` + `**我**/**助教**`）→ 剪贴板；剪贴板不可用降级为弹层手动复制                 |
| 重命名              | 行内编辑：会话项原地变 `.sren` 输入框，Enter 保存 / Esc 取消 / 失焦保存，上限 60 字（服务端截断）           |
| 删除                | 危险色 + **二段确认**（原地变红「确认删除？」再点执行）；删除当前会话自动开新空会话                          |
| 未落盘会话           | `_pending` 占位项不弹菜单                                                                               |

## 三、实现要点

- **前端单页**：全局 `#ctxMenu`（`position:fixed` 光标定位 + 右/底缘翻转，`mousedown` capture 外点关 / Esc 关 / scroll+resize 关）。
- **后端两点**：
  - `POST /api/session/update`：`conversation_id` + `title`（非空截 60）/ `pinned`（须 bool）；至少一字段；未知会话 404 `session_not_found`。
  - `POST /api/session/delete`：删会话（消息 + 元信息），不存在 404。
  - 均须加入 `do_POST` 的 **payload 解析白名单**，否则 `payload` 未定义直接 500。
- **存储层** `LearnerMemory`：`touch()` 扩 `pinned`/`bump`；`delete_session()` 删会话 + 清 `_msg_seq`。
