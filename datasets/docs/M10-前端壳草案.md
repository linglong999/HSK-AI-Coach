# M10 前端壳 · Explore 范式映射草案（v0.1）

- **日期**：2026-08-28
- **参考产品**：[ai.explore.poker]（Explore，对话驱动的知识卡片网状生长工具）
- **定位**：把 Explore 的交互壳装进 HSK-AI-Coach 的确定性偏误图谱内核。**界面自由，数据规则。**

## 一句话

> 动画层面像白板自由，数据层面是强约束的偏误知识网格。

## 逐项映射表

| Explore 元素 | 我们的对应物 | 映射方式 |
|---|---|---|
| 侧边栏项目树 | `learner_id × 等级(HSK) × 母语` | 一个"项目"= 一个学习者，天然隔离多学生 |
| 对话输入框 + LLM 选择 | 模式一·纠错闭环 | 输入中文 → 识别引擎；LLM 下拉透明化"识别/讲解"双引擎 |
| 文档阅读 | 模式二·文件讲解 | 打开一篇文章 → 选中片段 → 判定分流（偏误/泛讲解） |
| 新建卡片 | 新偏误/新知识点落图 | 一条错句沉淀为一个图谱节点 |
| 发散卡片 | 关联知识点生长 | 沿 **图谱边**（错误→知识点→混淆）向外扩 |
| 分支卡片 | 混淆分支 | 易混对（如在/再）另一分支单独成卡 |
| 知识宇宙 | 认知地图可视化 | Nodes+Edges 画布，复习队列高亮"待复习点" |
| 卡片 AI 正文 | 费曼讲解 + key_points | 卡片点开=四段式讲解，供复述验证 |
| 常驻对话 | 复述 / 尾随追问 | 对话里贴复述 → 验证引擎 → verdict 写回图谱 |
| 流式输出 | 讲解流式回显 | 生成时卡片内实时滚动 |

## 核心差异：必须防"自由发散"

- **Explore**：卡片可发散到任何地方（天文、编程、历史）。
- **我们**：卡片只能沿着权威边生长——`KP 节点 → 关联知识点 → 混淆边 → 已学/待复习`层级由偏误图谱 + HSK 知识清单 + 确定性校验决定。
- 界面层让用户感觉"在自由探索"，但每条新卡背后都是确定性的图谱路由。**守住架构铁律：Agent 不直接对话、图谱唯一权威源。**

## 三层复用策略

1. **界面层（借壳）**：深色沉浸、项目树、卡片画布、圆角卡片、流式——直接借鉴。
2. **交互层（借范式）**：对话驱动卡片生长、发散/分支动效——借鉴。
3. **数据层（我们内核，不借）**：图谱节点/混淆边/幂等/aging/复习队列——这些**控制"能看到什么、能往哪长"**，是 Explore 没有而我们独有的价值。

## M10 MVP 范围建议（不一步到 Electron/React）

- **单页 HTML 画布**即可承载第一版：一个项目=一个学生，输入中文→纠错卡片，卡片点开看费曼讲解，可从卡片"发散"出关联 KP，复习队列以"下一张卡"呈现。
- 先不做：多用户云同步（对应 Explore 会员墙）、语音、跨端。
- 后端复用的 `engine`（零依赖、纯本地），前端只做画布调用。
