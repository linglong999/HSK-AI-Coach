# 义项分拣成本评估 · §4a/§4b 切法依据（2026-09-21）

> 性质：`D-5 义项分拣成本评估 → §4a/§4b 切法` 的**实测成本数据**。方法论 = 单义词→多义词全量扫描（词典口径）+ 小样本教学口径判定校准。数据源自 CC-CEDICT（词典口径，seed=20260921 可复现）。
> 结论先行：**倾向 §4a（义项作属性/子键、主键不动）**，§4b（主键切词义项）的配置经费不划算——理由见 §5。

## 2. 教学口径校准（小样本判定）

从"词典口径多义词"池里**分层随机抽样 32 词**（义项数 2/3/4/5-8/9+ 分层，跨 1-4 级），逐词按 HSK1-4 教学语境判定"是否需独立调度"：

| 层（CC义项数） | 抽样 | 计 Y |
|---|---|---|
| 2 | 8 | 0 |
| 3 | 7 | 0 |
| 4 | 6 | 1（打） |
| 5-8 | 6 | 0 |
| 9+ | 5 | 1（起） |
| **合计** | **32** | **2** |

**样本教学口径需拆比例 ≈ 6%**（2/32）。判定表见 `sense_split_sample.md`。

## 3. 关键认识：词典口径 ≠ 教学口径

CC-CEDICT 的"多义项"大量是**噪音**，教学语境不构成独立调度需求：
- **同义英文重复**：可怕=10 义项全为 scary 类同义；色彩=6 义项围绕 color。
- **异读拼音**：累[rope 义] vs 学习语境"累[lèi]疲乏"；似的 台湾音。
- **无关量词/部首/通胀**：企业+CL、鸟+部首/方言粗口、全身+排版 em。

因此 **2236 是"发音/书写层面的词条"多义数，不是"教学需拆"的多义词数**。若直接按 2236 定 §4b，是拿词典口径去套教学切义项，配置经费被高估 3-5 倍。

## 4. 三档规模估算（供 §4 决策）

| 口径 | 规模 | 说明 |
|---|---|---|
| 词典口径（义项≥2，上限） | 2236 | 只当候选池，非工作量 |
| 教学口径·抽样外推（≈6%） | **≈134** | 32/2236×抽样比粗略下界，真实教学"真拆"量级 |
| 教学口径·论文锚点（保守上界） | 434 | CCL-2016 教学筛选重点多义词 |

> 抽样样本较小（32 词），**≈134 是量级信号不是精值**；434（论文）作为上界已很宽。

## 5. 判定（→§4a/§4b 切法）

对照总纲 §4 触发阈值（`≤400 词`时考虑 §4b；`§4a 属性方案覆盖≥80%` 时否决 §4b）：

- 教学口径"真需独立调度"的多义词量级 **≈134–434**，落在 §4b 预判线（≤400）**内沿但敏感**——若取论文上界 434 则略超线。
- **但关键不在数量，在"§4a 能否覆盖"**：真需独立调度的多义词（打、起这类）是少数，绝大多数可作属性/子键挂在 `kp_id` 下，**§4a 属性方案可覆盖 ≥80% 独立调度用例** → 按 §4 触发线，**否决 §4b，选 §4a**。
- **§4b 代价不对称**：主键切词义项 = error_count/mastery/unfixed_streak/FSRS 全重挂 + P0.2/0.3/0.4/0.17 返工 + **710 测试**大面积重写，而收益仅"少数词能独立调度记忆"，**性价比低**。
- **结论**：**先用 §4a**（义项作 Node 属性/子键，主键不动）。把「打/起/满」等真多义词列为**白名单**，起初值即可验证价值；若后续教学数据证明白名单多义词需独立 FSRS 调度，再评估 §4b 增量。

## 6. 落地建议（§4a 起步）

1. `kp_id` 主键不动；义项作 Node 新字段 `senses[]`（词形+义项+例句语境）。
2. 建**多义词白名单**（初值可从"高义项+教学高频"交集筛出，如打/起/满/点/带/包/去/上/下…），不在白名单的词默认单义，不硬拆。
3. 复习队列按 §4（2026-09-21 锁）词义项+例句语境设计，但**先在白名单词上生效**，非全词表。

## 7. 结论（回填总纲 §4 阈值）

- **§4a/§4b 切法**：选 **§4a**（首次定稿）。
- **预判线回填**：教学口径"需独立调度"多义词量级 ≈134（抽样外推）/ 上界 434（论文）→ 均干净落在 §4b 预判线附近或以内，但**因 §4a 可覆盖 ≥80%，触发"否决 §4b"**。
- **白名单多义词规模**：待实施时从"义项数≥5 + HSK1-4 高频"筛出初值，量级估百以内。
- **手段修正**：不再以"词典口径 2236"为切义项依据，改为"教学口径白名单"。
