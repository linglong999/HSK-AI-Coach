## 1. 设计决策（已拍板）

| 决策点 | 结论 |
|--------|------|
| 记忆载体 | **JSON 文件 + tmp+rename 原子写**（延续零依赖铁律，不用 SQLite/IndexedDB） |
| 存储结构 | **messages 追加式 + 会话状态快照**（双记录，仿 OpenMAIC `chat_message`+`chat_session_state`） |
| 上下文注入 | **确定性摘要注入**，非全量塞入（仿 `summarizeConversation`：最近 N 条×单条字符上限） |
| LLM 摘要 | **M6 有 Key 后升级**；M5 先做确定性摘要（无 Key 可测） |
| 规范化 | **注入前过滤**（对齐 OpenMAIC `visibleChatMessages`：不暴露 system/raw tool payload） |
| 隔离维度 | `channel: learner_id : session_id`（仿 `chat:<stage>:<learner>:<session>`） |
| M5 边界 | **只做对话历史持久化 + 简易画像字段**；偏误正式入图谱/复习队列归 M8 |

## 2. 借鉴开源的设计（OpenMAIC 一手结论）

以下直接取自 OpenMAIC 源码研读，标注源文件：

| 借鉴点 | 源（OpenMAIC） | 本项目落地 |
|--------|---------------|-----------|
| `ChatSession` 会话模型 | `lib/types/chat.ts` | `LearnerMemory` 顶层 session 对象 |
| messages 与 metadata 分离 | `UIMessage<ChatMessageMetadata>` | 每条 msg = `{role, content, metadata}` |
| append-only 历史 + 状态快照 | `chat_storage-core.ts`（`chat_message`+`chat_session_state`） | `messages[]` 追加 + `latest` 快照 + message id 索引 |
| 最近 N 条截断 | `chat_storage-core.ts` `MAX_MESSAGES_PER_SESSION` | 持久化裁剪窗口上限 |
| 确定性摘要 | `summarizers/conversation-summary.ts`（recent 10×200字符） | `get_summary()` 复刻 |
| 注入规范化/不暴露 system/raw | `personal-history-tools.ts` `visibleChatMessages` | `to_llm_history()` 只透 user/assistant |
| learner/session 隔离 key | `chat_storage-core.ts` `runtimeSessionId` | `learner_id / session_id` 双层 |

**刻意不搬**（与零依赖铁律冲突）：
- LangGraph / Pi agent runtime（你已定零框架）
- IndexedDB / Postgres RuntimeStore（本地零依赖用 JSON）
- Web Locks（Web 专属；单进程原子写用 os.replace 已够）
- Dexie 迁移层（初期无历史包袱）

## 3. 数据结构（JSON 文件，`data/memory_<learner_id>.json`）

```json
{
  "learner_id": "u_01",
  "profile": { "native_lang": "", "hsk_level": 3, "created_at": 0 },
  "sessions": {
    "sess_001": {
      "id": "sess_001",
      "created_at": 0,
      "updated_at": 0,
      "title": "",
      "status": "active",
      "message_ids": ["m1", "m2", "m3"],
      "messages": [
        {"id": "m1", "role": "user", "content": "…", "metadata": {"ts": 0}},
        {"id": "m2", "role": "assistant", "content": "…", "metadata": {"skill": "identify_errors"}},
        {"id": "m3", "role": "user", "content": "…", "metadata": {"ts": 0}}
      ]
    }
  }
}
```

- `role` ∈ `user / assistant`（注入时 server 的 `system` 不进 messages，作为每会话独立 prompt 常驻）
- `message_ids` 快照：会话状态索引（仿 `chat_session_state.messageIds`）
- 每条消息 `id` 单调自增（`m1, m2, …`）

## 4. 类设计（`engine/memory/learner_memory.py`）

```python
class LearnerMemory:
    """按 learner 隔离的多轮对话记忆。JSON 原子写，零依赖。"""

    DEFAULT_WINDOW = 20        # 注入窗口上限（对齐截断思想）
    SUMMARY_N = 10             # 摘要最近条数
    SUMMARY_MAX_CHARS = 200    # 单条摘要字符上限
    PERSIST_WINDOW = 200       # 持久化裁剪窗口（对齐 MAX_MESSAGES）

    def __init__(self, learner_id="default", root="data"): ...
    # 路径：data/memory_<learner_id>.json

    # ---- 写 ----
    def append(self, session_id, role, content, metadata=None) -> str: ...
    #   断言 role ∈ {user, assistant}；追加后裁剪到 PERSIST_WINDOW；原子写；返回 msg id

    def touch(self, session_id, title=None, status=None) -> None: ...
    #   更新 updated_at / title / status（不 append）

    # ---- 读（LLM 注入前）----
    def get_history(self, session_id, window=DEFAULT_WINDOW) -> list[dict]: ...
    #   取最近 window 条原始消息（含 metadata，供内部调试/检索）

    def to_llm_history(self, session_id, window=DEFAULT_WINDOW) -> list[dict]: ...
    #   规范化：过滤 system/raw → 只透 user/assistant {role, content}（对齐 visibleChatMessages）

    def get_summary(self, session_id, n=SUMMARY_N, max_chars=SUMMARY_MAX_CHARS) -> str: ...
    #   确定性摘要：最近 n 条 × 单条 max_chars 截断，仿 summarizeConversation

    def get_profile(self) -> dict: ...
    def update_profile(self, **fields) -> None: ...

    # ---- 检索 ----
    def search(self, query, limit=5) -> list[dict]: ...
    #   按 content 含 query 跨消息搜索（返回可见 msg，不暴露 metadata 敏感项）——M5 简化版

    # ---- 内部 ----
    def _load(self) -> dict: ...      # 文件不存在返回空骨架
    def _save(self) -> None: ...      # tmp + os.replace 原子写
```

## 5. 上下文注入拼接（供 Planner 演进）

```python
# runner 里构造（不在 M5 内，供说明）
def build_mem_context(mem, session_id):
    history = mem.to_llm_history(session_id, window=20)
    summary = mem.get_summary(session_id)
    profile = mem.get_profile()
    return {
        "profile": profile,
        "summary": summary,
        "recent": history[-5:],   # 最近 5 轮全量放行
        # 更早的由 summary 承载（防上下文爆炸，仿 OpenMAIC Director compaction）
    }
```

注入优先级（对齐 OpenMAIC compaction 思想）：当前题目上下文 > 最近 5-10 轮 > 会话摘要 > 长期画像 > 按需检索。

## 6. 验收标准

- [ ] `append` 追加消息正确落盘，role 非法拒绝
- [ ] 裁剪：超 `PERSIST_WINDOW` 后只留最近 N 条
- [ ] `to_llm_history` 只透 user/assistant，过滤 system/raw tool payload
- [ ] `get_summary` 确定性摘要：最近 n 条×单条 max_chars 截断，可复现
- [ ] 原子写：tmp+rename，`_save` 后无 `.tmp` 残留
- [ ] 按 learner_id 隔离：不同 learner 互不影响
- [ ] 零新增依赖（仅 stdlib）
- [ ] 全部既有测试 PASS（56 → 新增后仍全绿）

## 7. 边界声明

- M5 不把讲话内容写入偏误图谱/复习队列（归 M8，防图谱被自由对话污染——宁漏勿错铁律）
- `profile` 仅存简易画像字段（native_lang / hsk_level），不存诊断结论
- LLM 生成摘要、跨会话认知追踪归 M6/M7
