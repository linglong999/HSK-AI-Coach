## 2. 借鉴 / 偏离 OpenMAIC（一手结论）

### 借鉴（源：`in-memory-lexical-index.ts`）

| 借鉴点 | 本项目落地 |
|--------|-----------|
| 返回 chunk 原文 + 来源定位（locator：source_id/knowledge_point/heading） | Hit 携带 `kp_id/level/error_types/source`，Source 引用防编造 |
| 打分 `coverage + phraseBonus`（matched/queryTokens + 0.25） | `score = coverage + phrase(+0.25) + heading/kp(+0.1) + level(+0.05)` |
| capabilities 声明 `vector:false`，lexical 真源 | 仅词法，无向量，对齐零依赖 |
| metadata 过滤 | 支持 `level`/`error_types` 过滤 |
| version 原子重建 | `resource_version_id` 哈希 + tmp+rename 原子写 |

### 偏离（它对 HSK 不友好 / 依赖第三方）

| OpenMAIC 做法 | 问题 | 本项目改法 |
|---------------|------|-----------|
| 中文单字 token（`\p{Script=Han}`） | 语法词（把字句）被拆散，召回差 | 单字 + 术语白名单成词索引 |
| `graphemer` 第三方库 | 零依赖铁律 | Python 字符边界近似 |
| 全量扫描无倒排 | 数据大时性能差 | posting list 候选集缩小 |
| ingest 文档/HTML 管线 | 太重 | 三源直接结构化 ingest（无文档解析） |

## 3. 索引结构（Engine: `engine/rag.py`）

```
HSKLexicalIndex
  chunks: dict[chunk_id -> chunk_record]
  posting: dict[token -> set[chunk_id]]
  term_whitelist: set[str]        # 术语白名单（把/被/量词/结果补语…）
  _version(resource + sha256)     # 原子重建依据
```

chunk_record（对齐 OpenMAIC locator 防编造）：
```python
{
  "id": "kp-ba-sentence",          # chunk_id
  "source": "knowledge_point|lexicon|graph",
  "text": "“把”字句 重点：结构把+宾语+动词+补语，处置义",
  "kp_id": "kp-ba-sentence",
  "knowledge_point": "“把”字句",
  "level": 3,
  "error_types": ["语法"],
  "heading": "把字句",             # 术语词，标题命中加权
  "note": "…"
}
```

## 4. 分词（决策 B-乙）

```python
def tokenize(text):
    tokens = []
    # 1) 术语白名单整体命中加入（如 "把字句"/"结果补语"/"了着过"）
    for term in term_whitelist:
        if term in text: tokens.append(term)
    # 2) CJK 单字
    tokens += [c for c in text if '\u4e00' <= c <= '\u9fff']
    # 3) 英文/数字
    tokens += re.findall(r'[A-Za-z0-9_]+', text)
    return tokens
```
白名单来源：知识清单中提取的 `knowledge_point` 去掉标点（把字句/被字句/量词/比较句…）+ 词表核心语法词（了/着/过/的/地/得）。

## 5. 打分（决策 C-乙）

```python
def score(chunk, query_tokens, query_text):
    ct = set(tokenize(chunk["text"]))
    matched = query_tokens & ct
    if not matched: return 0
    coverage = len(matched) / len(query_tokens)
    s = coverage
    if query_text in chunk["text"]: s += 0.25        # phrase
    chk_heading = chunk.get("heading")
    if chk_heading and chk_heading in query_text: s += 0.10  # 标题命中
    if chunk.get("kp_id") and matched & {chunk["kp_id"]}: s += 0.05
    if chunk.get("level") == exact_level_query: s += 0.05
    return round(s, 3)
```

## 6. 检索接口

```python
def query(text, top_k=8, level=None, source=None, preferred_kp_first=True):
    q_tokens = set(tokenize(text))
    if not q_tokens: return []
    candidates = union(posting[t] for t in q_tokens)   # 倒排缩小候选
    if source: candidates &= posting_source[source]
    if level: candidates &= {c for c in candidates if chunk[c]["level"]==level}
    hits = [(chunk[c], score(...)) for c in candidates if score>0]
    hits.sort(key=lambda h: (-h[1], h[0]["id"]))
    return hits[:top_k]   # Hit 含 source/kp_id/text，供 Source 引用
```

## 7. 三源摄入（决策 D-乙）

| 源 | 读出 | 每个 chunk |
|----|------|-----------|
| knowledge_points | `knowledge_point/level/error_types/note` | 1 kp → 1 chunk |
| lexicon | word_level | 1 词 → 1 chunk（text=词, level） |
| graph | `get_kp` / `get_review_queue` 节点 | 被确认节点 → 1 chunk（marker `in_graph=true`，差异化） |

graph 源 ingest 用 `ErrorGraph.get_review_queue()` 待复习节点 + `get_kp` 详情；无图谱时该源为空（不报错）。

## 8. 接入（改变 `skills/lookup_knowledge_point`）

原实现是**字符串子串遍历**（无排序/无打分/无双语加权）。M7 替换为走 `HSKLexicalIndex.query`：
- `kp_id` 精确 → 直接取
- `keyword` → `query(keyword, top_k=5)`，返回排序后 hits（**默认 prefer 知识清单命中的 kp**，`preferred_kp_first`）

保留原有 `_error` 协议与 `count/results` 结构，不破坏下游（planner dispatch / 前端契约）。

## 11. 边界声明

- 纯词法，**不引入 jieba/向量**，对齐"零第三方依赖"铁律。
- 术语白名单为**耦合集**，随知识清单扩充；单字兜底保证未见术语也能召回。
- graph 源反映"当前"图谱（待复习/已确认），不进搜索历史；版本重建原子写（tmp+rename）。
- `preferred_kp_first` 保证知识清单命中优先于词表，防止泛词（了/的）抢镜知识点。
