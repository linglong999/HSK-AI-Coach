## 1. 目标与边界

- **产出**：把《交际汉语》（40 课 / 4 册 / 每册 10 课）的 A 类高频场景，抽取为结构化 JSON，写到 `datasets/scenarios_hnys/`。
- **MVP 范围**：**先取 3 个高频 A 级场景**（非硬性，可全量提，但 MVP 交付时只产出 3 个的成品值；若要全量，按「先行 3 个→校验→再扩」的节奏，勿一次性吞全量）。
- **体例底板**：该书单课固定 **7 板块**——〔会话〕[情景对话] → 〔生词〕 → 〔常用语句〕[高频实用句] → 〔文化背景知识〕 → 〔语言点〕[语法/用法，常 1–3 小点] → 〔注释〕 → 〔替换练习〕。
- **主线**：以「话题 → 情景对话 → 文化/语言点讲解 → 替换练习」的强结构化循环为纲抽取。

## 2. 板块 → 产出字段映射（唯一真源）

| 原板块 | 提取为 | 落到 JSON 字段 |
|---|---|---|
| 〔会话〕话题 | 场景名 | `scenario` |
| 〔会话〕话轮片段 | 场景锚点 / 话轮语料 | `turns[]`（每轮 = {speaker, line}） |
| 〔常用语句〕 | 得体例句对 /"该怎么说"高频句式 | `expressions[]`（每例含 message + 来源课号） |
| 〔文化背景知识〕 | 得体性语境补充（如称呼得体性） | `culture_notes[]` |
| 〔语言点〕 | 构式/语法资源（**并入 B 类语法资源，非「得体锚点」**） | `constructions[]`（挂语法锚点） |
| 〔生词〕〔注释〕〔替换练习〕 | 辅助语境（可作例句语境补强） | 可选挂靠，非必填 |

**映射主旨**：〔会话〕→ 场景索引进；〔常用语句〕→ 得体高频句式进；〔文化背景〕→ 得体语境；〔语言点〕→ **构式锚点，与语法资源（B 类，《HSK标准教程》）汇流，此处不负责任何语法讲解**。

## 3. 输出 JSON schema（`datasets/scenarios_hnys/`）

每场景一个文件，命名 `scn_{NN}.json`（NN=课号两位，如 01）。顶层为一个场景对象：

```json
{
  "scenario_id": "hnys-01",
  "source": {
    "book": "交际汉语",
    "book_no": 1,
    "lesson": 1,
    "lesson_title": "（原书课名）"
  },
  "scenario": "（中文话题名，如：问候与自我介绍）",
  "level_infer": "（从原书词汇/语言点起步难度推断，如 A 级 / 初等）",
  "turns": [
    { "speaker": "甲", "line": "原文话轮，一字不改" }
  ],
  "expressions": [
    { "zh": "高频句式原文", "note": "可选·用法/得体语境说明，仅当原书注释可佐证时填，禁自由发挥" }
  ],
  "culture_notes": [
    { "topic": "（文化背景主题）", "point": "得体性语境补充" }
  ],
  "constructions": [
    { "anchor": "（语言点/语法结构，如「吗」疑问句）", "via": "lesson-N-language-point" }
  ]
}
```

### 字段守则
- `turns[].line`、`expressions[].zh`、`culture_notes[].point`：**一律是教材原文，不允许改写、润色、补全**。宁缺毋滥——原文没明确给的就**留空数组/`null`**，绝不编。
- `note` / `point`：只在原书〔语言点〕〔注释〕或〔文化背景〕明示时才填一句话概括；查无即不填。
- 禁引入教材外的"规范答案"——这是**场景语料**，不是讲义。

## 4. 执行步骤（执行方按序跑）

1. **定位教材**：确认《交际汉语》电子版/PDF 可用；无电子版先与需求方确认扫描/OCR，**不臆测课名与话轮**。
2. **抽 3 个高频 A 级场景**为 MVP：优先〔问候与自我介绍〕〔点菜/饮食〕〔问路/购物〕这类基础交际，若原书有更贴近的课则按原书实际标题选。选定后把场景 ID 及课号写进一份 `MANIFEST.md`，列明"选了哪 3 课、为什么算 A 级高频"。
3. **逐板块抽取**，按 §2 映射表落到 §3 schema，忠实原文。
4. **自检**：所有 `zh`/`line` 字段均与教材原文逐字一致（可回源检索）；无人工补全的希望"留空不编"。
5. **产出**：3 个 `scn_{NN}.json` + `MANIFEST.md`，置于 `datasets/scenarios_hnys/`。

## 5. 验收标准（执行方自查 / 需求方复核）

- [ ] `constructions` 只做锚点登记，**不得夹带任何语法讲解内容**。
- [ ] 文件命名、schema 字段名与 §3 完全一致。
- [ ] 每课的 7 板块都已核对（缺板块 = 该字段留空并注明，不是漏抽）。
