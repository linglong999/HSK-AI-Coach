> 执行说明：**只做教材结构规则的提取，不二次创作、不改写教材例句**。忠实于原书"注释"板块。

## 2. 板块 → 产出字段映射（唯一真源）

语法资源来源在〔注释〕，构式/搭配在〔练一练〕〔比一比〕，词例在〔词语例释/搭配/辨析〕（4+ 级）。映射：

| 原板块 | 提取为 | 落到 JSON 字段 |
|---|---|---|
| 〔注释〕·语法点标题 + 讲解 | 语法点 head + 定义/规则 | `grammar` / `explanation` |
| 〔注释〕·表格固定句式 | 构式框架（"主语+结构+谓语"） | `pattern` |
| 〔注释〕·课文原句高亮 + 例句 | 示例句（**注明来源**：课文原句 vs 补充例句） | `examples[]`（`src=text/extra`） |
| 〔练一练〕（教程3+） | 构式确认/产出练习参考 | 可选 `drill_hint`（非必填） |
| 〔学一学·比一比〕（教程4+） | 易混词构式辨析 | 可选 `confusable[]`（非必填） |
| 〔词语例释/搭配/辨析〕（教程5上+，超纲本批不取） | — | — |
| 课号 / 级别 | 来源定位 + HSK 等级（构式锚点需关联知识库） | `level` / `source` |

**映射主旨**：〔注释〕→ 语法点/构式/例句（**核心资产，全部提取**）；〔练一练/比一比〕→ 可选辅助，不阻塞主产出。**练习册（Workbook）默认不纳入**——若后续需句子题库/题型适配再用，见 §6。

## 3. 输出 JSON schema（`datasets/grammar_hskstandard/`）

每课一个文件，命名 `hsk_{NN}_L{LL}.json`（NN=教程册号 01–04，LL=课号，如教程3第7课 = `hsk_03_L07.json`）。第 4 级上/下各 10 课，第 4 上 = 册 04、第 4 下 = 册 05（本批仅到 05，教程 1–4 下共 60 课，册号 01=教程1、02=教程2、03=教程3、04=教程4上、05=教程4下）。顶层为一个课对象，内嵌语法点数组：

```json
{
  "book": "HSK标准教程",
  "book_no": 3,
  "lesson": 7,
  "lesson_title": "（原书本课标题）",
  "hsk_level": 3,
  "grammar_points": [
    {
      "head": "（语法点名，如「把」字句）",
      "explanation": "（原书注释讲解——中英双语均保留，中文为主、英文附注）",
      "pattern": "（原书表格固定句式框架，如「S + 把 + O + V + 补语」）",
      "examples": [
        { "zh": "课文原句或补充例句原文", "en": "（原书英文译文，若有）", "src": "text | extra" }
      ],
      "drill_hint": "（可选·练一练里的构式确认，仅当原书明示时简记）"
    }
  ],
  "confusable": [
    { "a": "易混词甲", "b": "易混词乙", "note": "比一比里的辨析要点" }
  ],
  "notes": "（可选·文化点/俗语等非语法补充，非必填）"
}
```

### 字段守则
- `zh` / `explanation` / `pattern`：**一律教材原文**，不允许改写/润色/补全。原书没明确给的留空/省略，绝不编。
- `examples[].src` 必须标 `text`（课文原句）或 `extra`（注释里的补充例句），**保留来源区分**——课文原句型例句可直接进构式记忆卡，补充例句只作理解用。
- `hsk_level` 对应原书级别（1–4，4 分上/下同一 level=4，靠 `book_no` 区分 04/05）。
- 空缺板块 = 留空字段并注明，不是漏抽（原则上〔注释〕必填）。
- 本批是**语法/构式资产**，产出**不含话轮/场景**；那些在 A 类规格另出。

## 4. 执行步骤（执行方按序跑）

1. **定位教材**：确认《HSK标准教程》1、2、3、4（上/下）电子版/PDF 可用；无电子版先确认扫描/OCR，不臆测语法点与例句。
2. **按课序抽取**：从课前〔注释〕板块逐条抽语法点 head/explanation/pattern/examples，按 §2 映射落到 §3 schema。教程 1–4 上（课号 01–15/01–15/01–20/01–10）优先；教程 4 下（册 05，01–10）随后。
3. **维护 `MANIFEST.md`**：记录各册实际课数、每课语法点数量、实测语言点总数（供 §3 计数校正），列明已处理/待处理课。
4. **自检**：所有 `zh/explanation/pattern` 与原书逐字一致；`examples[].src` 来源标对；无人工补全，宁缺勿编。
5. **产出**：`hsk_{NN}_L{LL}.json`（60 个）+ `MANIFEST.md`，置于 `datasets/grammar_hskstandard/`。
