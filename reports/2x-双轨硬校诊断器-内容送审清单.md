## 一、总体（v2 修订）

- 本批送审 = 三个受读者可见的判定类内容：**① C5 处置动词判定（收码范围）；② C5 合法例外判定机制；③ C3/C4/C6 判定归属统一**。
- **C5 判定逻辑（v2 沿审核意见 v2 建议稿 + 抽样校正）**：把字句（处置式）谓语中心，**不作为"动词词形黑名单"硬判**，而按**「动词义项 × 尾成分类型」结构判定**。心理/认知/感知/形容词类作把字句谓核时：
  - **命中处置义构成（NP+V+成/作/当作/当成/看作/看成/视为+宾）** → **合法**（把…当作朋友）；
  - **有致使性尾成分 R**（了/掉/得/在/到/给/成/完/干净/清楚/好，结果/趋向/状态补语）→ **合法或边缘**（把我忘了/把他恨得牙痒痒/把书看完了）；
  - **光杆（V 后无任何尾成分，仅有"把+宾语"，或仅状语）** → **fail**（"我把这件事知道"）。仅有状语者判 edge（"把房间好好打扫"教材口径有分歧，判 edge 不判 fail）。
- **背景**：C5 原写的 `{知道,认识,了解,明白,希望,喜欢,爱,想念,有,存在…}` 经考古确认是设计期示例起点；`syllabus_hsk30_2025.json` 把字句条目仅证明"谓词不可光杆"，未证明"动词可处置性"。本批基于**真实语料**把 C5 从"示例"升级为"可裁决判定"。

## 二、逐项送审清单（3 项）

### ① C5 处置动词判定

**①a-1 判据（审核意见 V2 建议稿 · 采纳为判定链骨架）**

```
IF  能愿/否定词 位于"把"之后（"把饭想吃"）    → C4  fail（终止）
ELIF 谓语中心为 不及物/动宾式（配价不足）       → C5-1 fail（终止：见面/结婚/散步/帮忙/毕业/上班…）
ELIF 谓语中心 ∈ 关系/判断类                    → C5-2 fail（终止：是/有/在/像/属于/姓/等于/存在）
ELIF 谓语中心 ∈ 心理/认知/感知/形容词类:
      IF 命中处置义构成（把…当作/看成/视为…）   → pass（合法处置义）
      ELIF 有致使性尾成分 R                     → pass / edge
      ELSE                                     → C5-3 fail（终止）
ELIF 谓语中心后无任何成分（仅"把+宾语"，光杆）   → C3  fail（终止）
ELIF 有尾成分但搭配错/位次错                   → C6  fail / edge
ELSE                                            → pass
```
**设计要点（承载审核意见）**：
- **单一主错原则**：同一输入最多产出一条 error，从机制落实"避免重复报错"。
- 优先级按**根因深浅**而非码位顺序：`C4（语序）> C5（配价/语义）> C3（光杆）> C6（搭配位次）`——"我把这件事知道"即使补"了"仍错，根因是语义（表 C5-3），不给 C3 误指引。
- **能愿/否定（P0-2）已移出 C5**，归 C4 语序（"把饭想吃"根因是语序不是处置义）。

**①a-2 枚举（抽样驱动）**：不再暴力枚举全部"不可处置动词"——**v2 判据下：能救活的不是个别词，而是整个心理/认知/感知/形容词类**（审核意见 P0-3 原话）。故不建"词形黑名单"，代之以**词表 POS/义项 + 尾成分结构**判定。须确认前提：`lexicon_hsk1_4.json` 含 POS 字段？（实测：**当前无 POS 字段**，见 §三）→ ①a-2 受此限制，见 §六"义项级歧义"。

**①b「忘/记得」（审核意见裁决 · 采纳）**：
- **「忘」不进 C5 黑名单，归 C3 管辖**。"把+O+忘+了/掉" = 遭遇类把字句（把钱包丢了/把机会错过/把他得罪了），口语高频且合法；"他把这件事忘"（光杆）不合法，那归 C3 光杆问题，非处置义问题。**移出 C5 ≠ 完全放行（留 C3 管光杆）**。
- **「记得」进 C5 默认 fail，但设救活通道**。"把这件事记得"（光杆）→ C3/C5 双不合法；"把这件事记得很清楚"（"得"字评价结构）→ **边缘可接受，判 edge 非 pass**（可接受度低于"把…忘了"，不宜放行、不宜硬判错）。

### ② C5 合法例外判定机制（审核意见：✓ 立项，机制改）

**v2（沿审核意见 P0-3，载体改为结构判定，弃"词形白名单表"）**：
- 审核意见认定原"动词词形白名单"载体错：**把字句合法性是谓语整体（V+R）表达致使/评价性结果**，R=结果/趋向/状态补语、了、掉、成/作/给。故：
- **载体 = "动词义项 × 尾成分类型"的结构判定**（沿上述 C5 判定链），**不是按词形建表**（按词形建表规模不可控且必漏）。
- **合法用例（审核意见补充，纳入判定覆盖）**：把门一推/把饭给吃了/把他叫醒/把这本书看完了/把他恨得牙痒痒/把孩子饿坏了。
- **学习者在界面如何呈现（P0-4 补）**：
  - 命中"处置义构成 / 有效尾成分" → **pass 或 edge**（不报错；edge 仅轻微标注，不打断对话）。
  - C5-3 fail（光杆心理/认知谓核）→ **引导重述正确说法**，不输出诊断术语。措辞草案（学习者可见）：
    > "这个动词不能在这儿直接用——把字句里，动词后面要有个结果或影响（比如『了』『完』『成』，或『得…』）。试试『我_____了这件事』？"
  - **禁止输出**"该动词无处置义"（"处置"是专业术语，HSK 学习者不可理解；审核意见 P0-4 原话）。

### ③ C3 / C4 / C6 判定归属统一（审核意见：✓ 方向通过，补 3 项定义）

**补定义（审核意见 §三·③）**：
1. **"光杆"口径**：动词后成分（补语/宾语/了着过/重叠/动量）为主判据；**仅有状语者（"把房间好好打扫"）判 edge 而非 fail**。"把+O+V+了"中"了"**计为尾成分**（合法）。
2. **C6 位次判定表**：C6 触发 = 有尾成分但（a）结果补语 V+结果 /（b）趋向补语 来/去+宾语位序 /（c）可能补语 V+得/不+C 共现 /（d）程度补语 形容词+得+C /（e）动量/时量补语与宾语/了/过/正在共现——逐查给 fail/edge（此为总纲 §2「补语5查」明细，已在总纲完整编码，本条仅声明归属）。
3. **规则优先级**：`C4 > C5 > C3 > C6`（§二①a-1 已含）。

**连带修订**：C6 的"光杆触发"删除归 C3 后，总纲 §2 C6 条目文字同步改写（列入实施清单）。**审核方 ③.5"把字句宾语须有定"疑缺口的裁定（v2 修正）**：审核方声明"未取得总纲 §2/附录B 原文"，故其"C1–C6 未覆盖宾语有定"系**未读全貌**——**总纲 §2 规格 line 155 C2「宾语倾向有定/已知」已覆盖此点**（含"显式数量强无定→fail_soft/可语境特定→edge"）。故**不单独立项**，仅需将 v2 判据中的 C2 明示对齐。学理复核（2026-09-21 调研）："把字句宾语须有定/有指"是公认规律但**边界在"无定宾语是否可语境特定"**——王力(1943)/王还(1985)/张伯江等支持"有定为常、无定须语境可辨识则为边缘可用"；HSK/对外汉语教学网页多把"*我把一本书看完"当错误，但正式教材将其列为明确错误判定条款的证据不足，故**判定以 edge 而非 fail 更稳**（总纲 C2 现行 fail_soft/edge 与学界一致）。

## 四、P0-3 抽样统计（定例外表 vs 主规则 · 2026-09-21 实测）

**来源**：CGED16 HSK 真实学习者语料 14517 句（书面正式体，议论文为主）＋ YACLC（已核对，样本束 1000 句中把字句仅 46、心理谓核仅 2 病句）＋ golden（15 把字句）+ syllabus 例句（31 条，多为句式声明）。

**抽样结论（CGED 收码「把＋心理/认知/感知谓核」43 个去重样本）**：

| 子类 | 样本数 | 合法率 | 备注 |
|---|---|---|---|
| 处置义构成（把…当作/当成/看作/看成/视为=把 NP 当作 X） | ~25 | **全部合法（~100%）** | 主导模式，占过半 |
| 非处置义心理/认知谓核 + 有效尾成分（了/得/给/掉） | ~10 | **合法或边缘** | 把我忘了/气得七孔冒烟/忘得一干二净 |
| 光杆 / 非处置义心理谓核 | 极少数 | **全为病句** | 正是 C5-3/YACLC 2 例那类 |

**对"例外表 vs 主规则"的裁决**（正是审核方 P0-3 要求的数据化判断）：

> **合法率远超 10%（过半至主流的清一色合法）→ 这批不是"例外表"，而是"主规则的一部分"。** 但"主规则"≠ 把心理动词全当合法——而是：**"把＋处置义构成 / 有效尾成分"是主规则（合法），"光杆/非处置义"才是需拦截的病句（C5-3）**。即：**C5 不应做"动词黑名单"，应做"尾成分结构判定的缺省合法 + 光杆拦截"**。
>
> 同时标注**语体局限**：CGED 为正式书面体，心理谓核把字句的真实高频域在**口语/文学**（"把他恨得牙痒痒"）。因此结构判定务必含**口语尾成分库**（够呛/死/坏/醒/哭/笑），不能只按书面"成/作/得"。**此为设计约束，非历史事实**。

**例外表是否立项**：**例外表（词形拯救清单）不立项**——载体已改为结构判定，无需词形白名单。**代之以"口语尾成分库 + 分类小表（心理/认知/感知/形容词 + 关系/判断 + 配价不足）"**，规模小、可维护、可核验。
