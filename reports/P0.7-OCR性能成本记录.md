# P0.7 · OCR 性能与成本记录

> RapidOCR（本地 ONNX 推理，Apache-2.0）；样例=HSK30 大纲清晰印刷体页（200 DPI 渲染）。
> 延迟=单图片全链路（检测+识别）独占耗时；成本=本地推理零 API 费。

| 样例 | 延迟(s) |
|---|---|
| chars_l1.png | 11.48 |
| vocab_l1.png | 4.05 |
| vocab_l2.png | 10.33 |
| **合计/3 样例均值** | **8.62** |

**结论**：清晰印刷体单页 OCR 延迟（均值 8.62s）可接受；本地 ONNX 无外部成本，仅 CPU 与内存。手写暂不支持（范围限定）。
