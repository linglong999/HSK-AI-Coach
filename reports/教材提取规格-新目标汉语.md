## 1. 目标与边界

- **产出**：把《新目标汉语 口语课本》按**话题单元 + 人物主线**抽取为结构化 JSON，写到 `datasets/scenarios_ntcs/`。
- **教材事实**（联网核实，2026-09-21）：北京语言大学出版社 · 主编毛悦 · **全 6 册**——
  - 第 1–4 册 = 零起点→准中级，各 **10 个话题单元**；
  - 第 5–6 册 = 中级，各 **15 个话题单元**（话题偏社会/世界，超出产品 HSK 1-4 锚定范围）。
  - **单单元固定 9 板块**：〔学习目标〕→〔导入〕→〔头脑风暴〕→〔生词总动员〕→〔任务及活动〕→〔语法点注释〕→〔学习后任务〕→〔自我评估〕→〔文化小贴士〕。
  - **人物主线**：以来华留学生「大龙」与其所住中国家庭的故事为任务示范主线，每单元新场景、每册一故事阶段。
- **产品锚定**：产品目标 = HSK 1-4 级 → **本案只取 1–4 册**（初/准中级，共 40 个话题单元）。5–6 册超纲，不纳入本批。
- **MVP 范围**：**先取 3 个高频 A 级场景**（非硬性，可全量提；MVP 交付只出 3 个成品值）。节奏 =「先行 3 个→校验→再扩」。

## 2. 板块 → 产出字段映射（唯一真源）

本教材是**任务式**，场景/话轮的载体在〔任务及活动〕，得体语料在〔文化小贴士〕，语法锚点在〔语法点注释〕。映射如下：

| 原板块 | 提取为 | 落到 JSON 字段 |
|---|---|---|
| 〔章节视角〕话题单元标题 + 人物主线阶段 | 场景名 / 剧情背景 | `scenario` / `story` |
| 〔学习目标〕 | 本单元交际目标/功能 | `goal` |
| 〔任务及活动〕**场景锚点主源** | 话轮语料 / 任务示范 | `turns[]`（对话式则={speaker,line}；任务式则={task,line}） |
| 〔语法点注释〕 | 构式/语法资源（并入 B 类语法资源，非得体锚点） | `constructions[]`（挂语法锚点） |
| 〔文化小贴士〕 | 得体性语境补充（得体锚点） | `culture_notes[]` |
| 〔头脑风暴〕〔生词总动员〕 | 话题词汇/辅助语境 | 可选 `topic_words[]`，非必填 |
| 〔导入〕〔学习后任务〕〔自我评估〕 | 辅助语境（任务扩展/自评脚本） | 可选挂靠，非必填 |

**映射主旨**：〔任务及活动〕→ 场景/话轮索引进；〔文化小贴士〕→ 得体锚点；〔语法点注释〕→ **构式锚点，与 B 类语法资源（《HSK标准教程》）汇流，此处不负责任何语法讲解**。〔学习目标〕→ 场景交际功能标签（供 §3 排序与 §7 场景包定位）。

> 注意与《交际汉语》版的差异：旧版〔常用语句〕承担"该怎么说"高频句式，本任务式教材**无独立常用语句板块**——该类语料从〔任务及活动〕示范中抽取，落 `expressions[]`（见 §3），不强行造"常用语句"。

## 3. 输出 JSON schema（`datasets/scenarios_ntcs/`）

每单元一个文件，命名 `scn_{RRNN}.json`（RR=册号 01–04，NN=单元号 01–10，如第 1 册第 3 单元 = `scn_0103.json`）。顶层为一个场景对象：

```json
{
  "scenario_id": "ntcs-0103",
  "source": {
    "book": "新目标汉语 口语课本",
    "book_no": 1,
    "unit": 3,
    "unit_title": "（原书单元名，如某册某单元话题）"
  },
  "scenario": "（中文话题名，如：点菜与饮食）",
  "goal": "（本单元交际目标，取自〔学习目标〕）",
  "story": "（可选·本节所属的大龙主线剧情阶段，若非人物主线单元则 null）",
  "level_infer": "（从原书起步难度推断，如 初等 / 准中级）",
  "turns": [
    { "speaker": "大龙", "line": "原文话轮，一字不改" },
    { "task": "（如是任务式，给任务提示）", "line": "原文示范句/话轮" }
  ],
  "expressions": [
    { "zh": "高频句原文（取自任务及活动示范）", "note": "可选·用法/得体说明，仅当〔文化小贴士〕〔语法点注释〕明示时填，禁自由发挥" }
  ],
  "culture_notes": [
    { "topic": "（文化小贴士主题）", "point": "得体性语境补充" }
  ],
  "constructions": [
    { "anchor": "（语法点/结构，如「吗」疑问句）", "via": "unit-N-grammar-note" }
  ],
  "topic_words": [
    { "zh": "话题核心词（可选，取自头脑风暴/生词总动员）" }
  ]
}
```

### 字段守则
- `turns[].line`、`expressions[].zh`、`culture_notes[].point`：**一律是教材原文，不允许改写、润色、补全**。宁缺毋滥——原文没明确给的就**留空数组/`null`**，绝不编。
- `turns` 允许两种子结构（对话式 `{speaker,line}` / 任务式 `{task,line}`），**保留教材原形态，勿强行统一成对话**。
- `note` / `point`：只在原书〔语法点注释〕或〔文化小贴士〕明示时才填一句话概括；查无即不填。
- 禁引入教材外的"规范答案"——这是**场景语料**，不是讲义。

## 4. 执行步骤（执行方按序跑）

1. **定位教材**：确认《新目标汉语 口语课本》第 1–4 册电子版/PDF 可用；无电子版先与需求方确认扫描/OCR，**不臆测单元名与话轮**。
2. **抽 3 个高频 A 级场景**为 MVP：优先第 1–2 册的基础交际单元（问候/自我介绍、家庭、饮食、购物、问路这类），以原书实际单元标题为准。选定后把场景 ID 及册/单元号写进一份 `MANIFEST.md`，列明"选了哪 3 个单元、为什么算 A 级高频"。
3. **逐板块抽取**，按 §2 映射表落到 §3 schema，忠实原文；任务式单元保留〔任务及活动〕的示范形态。
4. **自检**：所有 `zh`/`line` 字段均与教材原文逐字一致（可回源检索）；无人工补全的希望"留空不编"。
5. **产出**：3 个 `scn_{RRNN}.json` + `MANIFEST.md`，置于 `datasets/scenarios_ntcs/`。

## 5. 验收标准（执行方自查 / 需求方复核）

- [ ] 字段全部来自《新目标汉语 口语课本》原文，无改写、无补全、无外部规范答案。
- [ ] `turns` 保持原书形态（对话式 `{speaker,line}` 或任务式 `{task,line}`），未强行统一或打散。
- [ ] 3 个 MVP 场景真实对应当书某单元（MANIFEST 记录册号+单元号）。
- [ ] `constructions` 只做锚点登记，**不得夹带任何语法讲解内容**。
- [ ] 仅取 1–4 册；如误抽 5–6 册（中级/社会话题）即判定不合格。
- [ ] 文件命名、schema 字段名与 §3 完全一致（`scn_{RRNN}.json`，RR=册、NN=单元）。
- [ ] 每单元的 9 板块都已核对（缺板块 = 该字段留空并注明，不是漏抽）。
