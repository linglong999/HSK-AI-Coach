# HSK-AI-Coach

**面向 HSK 中文学习者的 AI 偏误纠错练习伙伴。** 输入一句中文或一段对话，它告诉你错在哪、为什么错、该怎么说，并把每次纠正沉淀进一张偏误图谱，过一段时间主动拉你复习。

> 一句话：拿它练习写/说中文，而不是拿它问答案。它更像一个"在你旁边只在你卡壳时才开口的陪练"，而不是一个会替你做题的老师。

- 全部用 Python 标准库实现，`clone` 即跑，不需要 `pip install`
- API Key 自备：默认 DeepSeek，可在界面「设置 → 模型密钥」直接加任意 OpenAI 兼容供应商（Qwen / GLM / Kimi / Ollama…）
- 每个能力都有可复跑的评测（黄金句集 + 真实模型实跑），不是"感觉效果不错"

---

## 这个项目解决什么问题

中文作为二语的学习者，练笔和口语后最缺的是**即时、能讲清原因的反馈**：

- 写完一句话，不知道哪里错了、为什么错、下次怎么避免——传统批改要等老师/成本高；
- 通用大模型能聊天，但给答案往往不解释系统性成因，也不连接 HSK 词汇/语法进度；
- 更糟的是"一开口就被逐句纠正"，很容易打击表达欲。

这个项目的回应，是把"**偏误检测 → 讲清原因 → 让学习者自己复述检验 → 沉淀进复习计划**"放进同一个闭环。核心原则一句话：**能交流就不打断，卡住才出手。**

## 它适合谁 / 不做什么

**目前设计给：** 以中文为第二语言、HSK 1–4 的中级学习者（英语母语起步），以及想批量改学生作业的教师。

**当前支持：** 简体中文 · 句子/短文纠错 · 自由对话与场景练习 · 初-中级语法/词汇反馈 · 英文/中文双语教学界面。

**当前不做（明确边界）：** HSK 5–6 学术写作评分 · 发音打分 · 真人老师替代。


```
python -m unittest discover tests -v
```

**403 个测试全部 PASS** 即说明链路完整（识别/讲解/图谱/降级兜底/前端服务层+界面静态不变量）。主要增量：0.19 前后端 profile/深链 11、0.20 供应商/BYOK 20、0.21 双语 25、0.22 母语迁移归因 25 + 场景对话 25 + 介入时机/个性化 50、0.23 前端静态不变量 3、0.24 会话右键菜单/置顶-重命名-删除 15。

**3. 命令行跑两种用法**

```bash
# 纠错闭环：输入一句中文 → 识别 → 讲解 → 图谱沉淀 → 出复习队列
python -m engine.demo_loop "我想买苹果很多。"

# 文件讲解：读一篇中文，选中片段 → 偏误走纠错链 / 正确句走泛讲解
```

**4. 启动前端壳（对话画布 + 认知地图）**

```bash

```

零依赖 HTTP 服务（仅标准库，原生 JS+SVG 单页，无需前端依赖）。左侧对话流呈现「偏误卡 → 讲解卡 → 学习成果卡」，侧栏进入「◈ 认知地图」看掌握度 × HSK 分布与复习队列。界面默认英文脚手架、中文内容载体（「设置 → 语言」切中文/英文），侧栏还有「📣 场景对话」与「设置 → 个性化」。自由对话（`/api/dialog`）需配置 LLM Key，未配置时前端直接报错并给出配置步骤（不静默降级）；仅用确定性纠错（`/api/process`）可不配 Key。

## 核心能力（场景 × 输出）

| 场景 | 你输入什么 | 得到什么 |
|---|---|---|
| 单句纠错 | "我想买苹果很多。" | 偏误定位、建议改法、错误类型 |
| 费曼讲解 | 有偏误的句子 | 四段式讲解（为什么错 → 正确说法 → 对比 → 验证） |
| 复述检验 | 用自己的话复述刚才的知识点 | 判定是否真的理解，不过则降难度重讲 |
| 文件讲解 | 一段中文 + 选中的片段 | 偏误走纠错链，正确句讲背景（不污染图谱） |
| 对话练习 | 自由聊天，或选一个场景卡（咖啡厅/问路…） | 边聊边静默记录，卡壳/求助时才纠 |
| 复习提醒 | — | 按图谱待复习队列，过段时间主动提醒 |

## 关键设计决策（为什么这样设计）

几条对教学结果影响最大的取舍，有对应的评测证据：

1. **宁可漏判，也不误报。** 教学场景里"教错"比"不教"更有害——误报会污染学习者已有的认知。所以干净句误报被确定性护栏压到 **0%**。代价是少数边界句可能不纠，我们接受。
2. **让学习者自己复述，而不是看一遍答案。** 看完答案随时会"懂了"，复述才能检验真懂。所以讲解后要求复述，连续 2 次不过降难度再讲。代价：互动更慢、对低容错学习者更累。
3. **能交流就不打断。** 二语学习者最伤动机的是"一开口就被逐句纠"。所以流利时对高置信偏误**静默记录**，只有求助/卡壳/连续出错才介入，打断上限由服务端强制。这来自任务型语言教学原则，代价是单次的"即时纠正"让位于长期表达欲。
4. **教学层用母语，内容层用目标语。** 英文解释规则、中文承载例句与词汇，降低认知负担（对标 HelloChinese 等成熟产品的策略）。
5. **图谱是唯一权威，AI 只能选路径不能改数据。** 纠错结论沉淀进偏误图谱（确定性数据层），避免模型"今天这么说、明天那么说"的漂移，也让结果可复现。代价：架构更重，模型自由度受限。
6. **每个决策都有数字。** 每块能力配黄金评测集 + 真实模型实跑，指标都能复跑核验，而不是"效果不错"。

## 架构

```
学习者输入 ───→ planner 自由 ReAct（唯一对话入口 /api/dialog）
                   │  按情况自由选择技能
                   ▼
          统一 Skill 注册表（9 技能）
          identify_errors / explain_error / verify_retell /
          lookup_knowledge_point / retrieve_corpus / get_review_queue /
          generate_unit / web_search / parse_document
                   │
       ┌───────────┴────────────┐
       │ 三引擎(识别/讲解/验证)    │  工具(搜索/文档/生成单元)
       └───────────┬────────────┘
                   ▼
      偏误图谱（确定性数据层，纯规则） KP 节点 / 混淆边 / 幂等 / aging
                   ▼
      serve.py：/api/dialog /api/process /api/graph /api/verify /
                /api/generate /api/profile /api/conversation /api/providers
```

几个支撑性设计：**自由在调度，约束在数据写**（planner 自由选技能，图谱写入经两段式 + 幂等键）；**LLM 只做带宽，规则做守门**（置信度决策 + 确定性护栏防过度纠正）；**降级兜底**（识别不可用时回退规则匹配，只产"待确认"候选，绝不污染图谱；某环节失败其余照常并记录 `degraded`）；HSK 等级对照官方词表防超纲幻觉。

## Roadmap（阶段 · 目标 · 理由）

已完成（按"先解决什么、为什么先做它"排）：

- **M1–M10 · 能力底座**：识别→讲解→复述→图谱→前端壳依次打通并逐项评测。理由：先验证"纠错这一件事能否做准、做稳"，再做交互。
- **0.17 · 架构反转**：把固定流程改为 planner 自由 ReAct + 技能注册表。理由：学习者问题千人千面，固定流水线接不住，改为"自由调度 + 数据写约束"。
- **0.19/0.20 · 前端壳 + 模型密钥**：卡片画布、认知地图独立视图、AI 学习报告；界面内加任意兼容供应商。理由：让非技术学习者也能独立跑起来，并摆脱单一模型依赖。
- **0.21 · 教学语言分层**：英文脚手架 + 中文内容载体。理由：降低初学者认知负担（对标成熟产品策略）。
- **0.22 · 习得伙伴转向**：① L1 母语迁移归因（从英→中偏误反推原因，假设仅供讲解不入图谱）② 场景对话（咖啡厅/问路等生活场景沉浸练习）③ 介入时机 + 个性化（能交流不打断，个性化可调风格/称呼/打断上限）。理由：从"纠错引擎"转向"让人愿意经常开口的陪练"——这是二语习得里比"纠得准"更影响成效的一环。

规划中：

- [ ] **M11 · 复习参数标定 + 评测扩集**：把 aging/mastery 等间隔复习参数标定到有证据的范围，并扩到汉字/词汇/语用评测。理由：当前复习队列规则有确定性保证但参数未经验证，需要数据而不是拍脑袋。
- [ ] 语言/场景扩展：HSK 5–6 学术写作、更多生活场景与本地小模型支持。
